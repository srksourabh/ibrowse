iBrowse v0.2.0

Hear any website and explore it by mouse, touch, keyboard, and voice — built for blind and low-vision users with subtle Indian English speech and optional Google Gemini Live & Claude fallback.

Download Extension (.zip) — Windows & macOS Open Mobile & Web App — iPhone & Android Presentation User Guide

Windows & macOS (Chrome, Edge, Brave)

  1. Download ibrowse-0.2.0-chrome.zip and unzip it to a folder.
  2. Open chrome://extensions (or edge://extensions / brave://extensions).
  3. Turn on Developer mode, click Load unpacked, and select the unzipped folder.
  4. Press Alt+I on any website to start Explore Mode, or Alt+O for Settings.

iPhone & iPad (Safari)

  1. Open the iBrowse Mobile Web App in Safari.
  2. Tap Share → Add to Home Screen to install it full-screen.
  3. Tap Initialize Audio & Haptics, then drag your finger to hear elements or tap Speak.

Android (Chrome or Kiwi/Mises Browser)

  1. Quick Web App (Chrome): Open iBrowse Mobile Web App, tap ⋮ → Add to Home screen.
  2. Full Extension on any site: Download ibrowse-0.2.0-chrome.zip, open Kiwi or Mises Browser → Extensions → Developer mode → + (from .zip).

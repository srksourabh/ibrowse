Windows & macOS

  1. Download ibrowse-0.2.0-chrome.zip and unzip it.
  2. Open chrome://extensions (or Edge / Brave).
  3. Enable Developer mode → Load unpacked → select the folder.
  4. Press Alt+I on any site to start, or Alt+O for Settings.

iPhone & iPad

  1. Open the Mobile Web App in Safari.
  2. Tap Share → Add to Home Screen.
  3. Tap Initialize Audio & Haptics, then drag or tap Speak.

Android

  1. PWA: open the Mobile Web App → Add to Home screen.
  2. Full extension: load the zip in Kiwi or Mises (Developer mode).

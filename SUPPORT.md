# Getting help

| I want to… | Go to |
|---|---|
| Learn how iBrowse works | [README](README.md), then the spoken tour (opens on install, replay it from settings) |
| Find a shortcut | The key table in the [README](README.md#keyboard-and-mouse) |
| Report a bug | [Bug report](../../issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](../../issues/new?template=feature_request.yml) |
| Add support for my haptic device | [Hardware profile](../../issues/new?template=hardware_profile.yml) and [sdk/README.md](sdk/README.md) |
| Report a security or privacy problem | [SECURITY.md](SECURITY.md), privately |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

Every issue form works with a screen reader. If a form or document is hard to use, that is itself a bug: please tell us.

iBrowse is maintained by volunteers. We read everything, but cannot promise a reply time.
